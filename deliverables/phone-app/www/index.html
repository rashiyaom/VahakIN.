Hotspot setup & server commands

1. Make sure laptop & phone are on the same Wi-Fi / Hotspot.

2. Start the VahakIN server on your laptop listening on all interfaces:

cd apps/web && npm run dev -- -H 0.0.0.0 -p 3000

3. If your laptop IP changed, find it with:

ipconfig getifaddr en0

4. In the app, tap Connect to VahakIN. The phone's GPS is ready to stream into the Owner Dashboard.
